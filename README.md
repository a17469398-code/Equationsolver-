# Smart Scientific Calculator

A feature-rich scientific calculator application with voice recognition support.

## Features
- ✅ Basic arithmetic operations
- ✅ Scientific functions (sin, cos, tan, log, ln, sqrt)
- ✅ Voice input support
- ✅ Calculation history
- ✅ Memory functions (MC, MR, M+, M-)
- ✅ Keyboard shortcuts
- ✅ Mobile-friendly responsive design
- ✅ Real-time calculation preview

## Platforms
- Web App (HTML/CSS/JavaScript)
- Android App (Native WebView - coming soon)

## Installation & Usage

### Web App
1. Clone the repository
2. Open `index.html` in any modern browser
3. Start calculating!

## Features Documentation

### Basic Operations
- Addition, Subtraction, Multiplication, Division
- Parentheses support for complex expressions

### Scientific Functions
- Trigonometric: sin, cos, tan (in degrees)
- Logarithmic: log (base 10), ln (natural log)
- Root: sqrt (square root)
- Power: x^y (exponentiation)
- Constant: π (pi)

### Memory Functions
- **MC**: Clear memory
- **MR**: Recall memory value
- **M+**: Add current result to memory
- **M-**: Subtract current result from memory

### Keyboard Shortcuts
- **Enter**: Calculate result
- **Escape**: Clear all
- **Backspace**: Delete last character

### Voice Commands
- Click 🎤 button to use voice input
- Supported commands:
  - "plus", "add" → +
  - "minus", "subtract" → -
  - "multiply by", "times" → *
  - "divide by" → /
  - "power" → ^
  - "square root of" → sqrt(
  - "open bracket", "close bracket" → ()
  - "point" → .

## Browser Compatibility
- Chrome/Chromium (full support)
